🤖 Автоматический режим: один раз настроить, дальше мониторинг в фоне

После запуска служб вам не нужно каждый день нажимать «поиск». Агент работает как фоновая служба и сам проверяет подключённые источники по расписанию.

Что работает автоматически

  • Поиск: агент опрашивает настроенные публичные источники каждые 90 минут (интервал меняется через AIRDROP_DISCOVERY_MIN).
  • Фильтрация и сохранение: найденные проекты сохраняются в локальную базу, повторные результаты объединяются, подозрительные формулировки получают штраф к рейтингу. Это эвристика, не гарантия безопасности.
  • Уведомления: новые находки и результаты проверок отправляются в ваш отдельный Telegram-бот, если токен и ID администратора настроены.
  • Повторная проверка: агент запускает проверки примерно каждые 6 часов, но только для проектов, у которых настроен поддерживаемый публичный checker в config/airdrops.json.
  • Перезапуск при сбое: systemd повторно поднимает агента и панель после аварийного завершения или перезагрузки VPS.

Ручной поиск на главной — необязательный запуск вне расписания. Чтобы расписание продолжалось, служба airdrop-agent должна иметь статус active.

Однократная настройка

  1. Установите или обновите проект скриптом deploy/updater.sh. Он клонирует ветку, если каталога ещё нет, либо fast-forward-обновит существующий клон, установит зависимости и перезапустит службы.
  2. Для Telegram-уведомлений задайте свой AIRDROP_BOT_TOKEN и AIRDROP_ADMIN_IDS. Токен бота, который уже публиковался в чате, сначала отзовите в @BotFather и выпустите новый.
  3. Проверьте, что агент и панель активны. Дальше мониторинг идёт автоматически; команда поиска нужна только для запуска вне расписания.
  4. Не храните на серверном кошельке средства, потерю которых не можете позволить. Экспорт seed-фразы даёт полный доступ к кошельку: никому её не передавайте.

Границы автоматизации — без обещаний «пассивного дохода»

Агент может автономно искать и проверять данные только там, где у проекта есть совместимый публичный checker. У большинства найденных объявлений такого API нет; их eligibility нельзя достоверно вычислить только по адресу кошелька. Такие находки не являются подтверждёнными выплатами.

Никакой законной системы нельзя честно обещать как гарантированный заработок: результат может быть $0, возможны комиссии, географические ограничения и потеря средств.

Ночной режим

Окно тишины по времени сервера. Часовой пояс не переводится — всё считается в UTC.

Сервер UTC: {{ server_utc_now }}
Например 23:00 — по времени сервера в UTC.
Например 07:00 — по времени сервера в UTC. Окно через полночь поддерживается.
В этом окне аккаунты не публикуют ходы сценария, не отвечают на сообщения, не ставят реакции и не выходят с автономными сообщениями; входящие сообщения по-прежнему сохраняются в контекст. Время берётся с сервера в UTC — сверьтесь с текущим значением справа от заголовка. Изменения применятся при следующем запуске чат-фермы.
